# PWA 접근성·실사용 베타 체크리스트

## 자동 검사

다음 항목은 `npm run check`에서 매번 확인한다.

- TypeScript 타입과 계산·저장소 회귀 테스트
- 프로덕션 PWA 빌드 성공 여부
- 한국어 문서 언어, viewport, 설명과 테마 색상
- manifest 이름·설명·시작 경로·scope·앱 ID·아이콘
- 서비스 워커의 HTML·manifest·아이콘 사전 캐시
- 키보드 포커스, 본문 건너뛰기, 동작 줄이기 스타일

## 실기기 베타

아래 항목은 배포 주소에서 실제 기기와 보조기술로 확인하고, 결과와 기기·브라우저 버전을 함께 기록한다.

### 키보드와 스크린리더

- 첫 Tab에서 `본문으로 건너뛰기`가 표시되고 본문으로 이동한다.
- 월급 4단계에서 이전·다음 이동 후 단계 제목을 읽는다.
- 오류가 발생하면 오류 요약과 연결된 필드 오류를 읽는다.
- 선택 버튼의 현재 상태를 `눌림` 상태로 구분한다.
- 저장 이력과 월별 변화 표의 제목·행·열 관계를 이해할 수 있다.
- 업데이트 알림에서 설명과 두 동작을 구분할 수 있다.

### 모바일과 설치

- 320px 너비에서 가로 페이지 스크롤 없이 핵심 동작을 완료한다.
- 월별 변화 표만 해당 영역 안에서 가로 스크롤된다.
- iOS Safari와 Android Chrome에서 홈 화면 추가 또는 설치 안내를 확인한다.
- standalone 실행 시 안전 영역과 상단·하단 고정 동작이 겹치지 않는다.
- 200% 확대에서도 입력·오류·버튼 내용을 읽고 조작할 수 있다.

### 오프라인과 데이터 복구

- 온라인에서 한 번 연 뒤 비행기 모드에서 홈과 저장 계획을 다시 연다.
- 오프라인에서 월급·여윳돈 초안을 작성하고 앱 재시작 후 복구한다.
- 새 버전 알림에서 `나중에`를 선택하면 입력이 유지된다.
- 업데이트 후에도 프로필·초안·저장 이력이 유지된다.
- 브라우저 저장 공간 삭제 전 확인 문구와 삭제 결과가 일치한다.
