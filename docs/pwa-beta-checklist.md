# PWA 접근성·실사용 베타 체크리스트

## 자동 검사

다음 항목은 `npm run check`에서 매번 확인한다.

- TypeScript 타입과 계산·저장소 회귀 테스트
- 프로덕션 PWA 빌드 성공 여부
- 한국어 문서 언어, viewport, 설명과 테마 색상
- manifest 이름·설명·시작 경로·scope·앱 ID·아이콘
- 설치용 PNG 192/512px, 별도 마스커블 PNG 512px, Apple 홈 화면 PNG 180px의 실제 크기·연결·사전 캐시
- 서비스 워커의 HTML·manifest·아이콘 사전 캐시
- 키보드 포커스, 본문 건너뛰기, 동작 줄이기 스타일

## 실기기 베타

현재 우선 검증 기기는 iPhone입니다. 백업 화면의 Safari 설치 안내에 따라 홈 화면에 추가한 뒤 실행하고, 비행기 모드 및 Wi-Fi 해제 상태에서 재실행하여 저장 내역을 확인합니다. 기기 간 데이터는 자동 동기화되지 않으므로 기존 기기의 암호화 백업을 옮겨 복원해야 합니다. 실제 iPhone의 결과·iOS 버전은 아직 확인되지 않았습니다.

2026-10-18 전체 회귀 검사: 자동 테스트 164개 통과, 실패·건너뜀 0개. 이 결과는 실제 iPhone 설치·파일 선택·다운로드·오프라인 동작의 통과를 의미하지 않습니다.

아래 항목은 배포 주소에서 실제 기기와 보조기술로 확인하고, 결과와 기기·브라우저 버전을 함께 기록한다.

### 키보드와 스크린리더

- 거래·계좌·목표 입력 변경 후 다른 메뉴로 이동하면 확인 대화상자가 열리고 계속 작성 또는 Escape로 취소하면 입력이 유지된다. Tab 포커스가 대화상자 안에 머무는지 확인한다.
- 입력을 원래 값으로 되돌리거나 저장·취소한 뒤에는 이동 확인이 나타나지 않는다. 입력 버리기 선택 시 요청한 화면으로 이동한다.

- 첫 Tab에서 `본문으로 건너뛰기`가 표시되고 본문으로 이동한다.
- 월급 4단계에서 이전·다음 이동 후 단계 제목을 읽는다.
- 오류가 발생하면 오류 요약과 연결된 필드 오류를 읽는다.
- 선택 버튼의 현재 상태를 `눌림` 상태로 구분한다.
- 저장 이력과 월별 변화 표의 제목·행·열 관계를 이해할 수 있다.
- 업데이트 알림에서 설명과 두 동작을 구분할 수 있다.

### 모바일과 설치

- 320px 너비에서 가로 페이지 스크롤 없이 핵심 동작을 완료한다.
- 월별 변화 표만 해당 영역 안에서 가로 스크롤된다.
- iOS Safari와 Android Chrome에서 홈 화면 추가 또는 설치 안내를 확인한다.
- standalone 실행 시 안전 영역과 상단·하단 고정 동작이 겹치지 않는다.
- 200% 확대에서도 입력·오류·버튼 내용을 읽고 조작할 수 있다.

### 오프라인과 데이터 복구

- 백업 화면에 저장 보호 상태가 표시되고, 버튼을 누르기 전에는 권한 요청이 발생하지 않는다.
- 저장 보호가 승인되거나 거부되어도 기존 거래는 유지된다. API 미지원·오류 시 보호 완료라고 표시하지 않는다.

- 온라인에서 한 번 연 뒤 비행기 모드에서 홈과 저장 계획을 다시 연다.
- 최초 캐시 설치 완료 시 오프라인 준비 안내가 표시되고 닫을 수 있다. 이 안내를 데이터 백업 완료로 표시하지 않는다.
- 서비스 워커 등록 실패 시 새로고침 안내, 업데이트 요청 실패 시 재시도 안내를 표시한다. 업데이트 확인 중에는 중복 요청을 막고 취소하면 다시 조작할 수 있다.
- 오프라인에서 가계부 거래·월급 계획을 저장하고 앱 재시작 후 저장한 값을 확인한다. 저장하지 않은 입력은 자동 복구 대상이 아니다.
- 새 버전 알림에서 `나중에`를 선택하면 입력이 유지된다.
- 업데이트 후에도 저장한 계좌·거래·목표·월급 계획과 이력이 유지된다. 변경 중인 입력은 업데이트 전에 저장하거나 버리기를 선택한다.
- 브라우저 저장 공간 삭제 전 확인 문구와 삭제 결과가 일치한다.
- 암호화 백업을 저장한 뒤 파일 검증으로 현재 내용과 일치하는지 확인한다. 검증 중 현재 데이터는 변경되지 않아야 한다.
- 잘못된 암호·손상된 백업은 검증에 실패하고 이전 성공 표시가 남지 않는다.
- 검증 후 거래를 변경하면 재검증 안내가 나타나고, 재검증 시 차이를 표시한다.
- 두 탭에서 같은 가계부를 열고 한쪽에서 거래를 저장한 뒤 다른 탭에서 백업 저장·파일 검증을 시도한다. 오래된 화면은 새로고침 안내를 표시하고 이전 데이터로 새 백업을 만들지 않아야 한다.

## 기록 양식

| 날짜 | 기기·OS | 브라우저·보조기술 | 시나리오 | 결과 | 메모 |
|---|---|---|---|---|---|
| YYYY-MM-DD | 예: Pixel / Android | Chrome / TalkBack | 오프라인 저장 후 재실행 | 통과·실패 | 재현 단계 |

설치 아이콘은 기존 SVG 로고에서 PNG로 변환했으며 마스커블 버전은 불투명 배경과 여백을 둡니다. SVG는 favicon으로 유지합니다. 참고: [web.dev 웹 앱 manifest](https://web.dev/learn/pwa/web-app-manifest), [MDN 앱 아이콘](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Define_app_icons). 빌드 검사는 실기기 설치 성공을 대신하지 않습니다.

2026-10-18 로컬 프로덕션 빌드 검증: 최초 오프라인 준비 안내와 닫기를 확인했습니다. 프리뷰 서버를 중단한 후 합성 계좌에 123,456원을 저장하고, 페이지 새로고침 후 자산 화면에서 이름·잔액 유지를 확인했습니다. 이는 서버에 접속할 수 없는 상황의 브라우저 검증이며 휴대폰 비행기 모드·앱 강제 종료·업데이트 실패 분기의 실기기 검증은 아닙니다.
