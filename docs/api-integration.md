# 개인 가계부 API 연동 상태

확인일: 2026-09-30. 개인 계좌 조회는 아직 연결되지 않았으며, 아래의 이용기관 참가 여부가 개별 상품 조회 가능 여부를 보장하지 않는다.

## 현재 저장소

- `FINLIFE_API_KEY`: 예금·적금 공식정보 수집기와 배포/정기 갱신 작업은 구현됨. GitHub 저장소 Actions 비밀값 목록은 현재 비어 있음. 키 내용은 조회하지 않음.
- 추적 중인 `apps/web/public/data/financial-products.json`은 수집 시각이 없고 컬렉션이 빈 초기 상태임.
- 2026-09-27 main 배포 작업은 성공. 2026-09-28 정기 실행에서는 코드 검증은 통과했으나 `Refresh official financial product snapshot` 단계가 실패해 배포는 건너뜀. 기존 배포는 유지됨.
- `.env.example`의 ECOS·공공데이터·로그인 관련 변수는 설정 자리이며, 이것만으로 API 기능이 구현되거나 연결된 것은 아님.

## 금융상품 API 활성화

1. 금융감독원 금융상품한눈에에서 사용할 인증키를 발급받는다.
2. [저장소 Actions 비밀값 설정](https://github.com/Leetaebeen/money-plan/settings/secrets/actions)에 이름 `FINLIFE_API_KEY`로 등록한다. 키를 소스·채팅·브라우저 설정에 넣지 않는다.
3. `CI` 워크플로를 수동 실행하고 공식정보 수집, 최신성 검증, Pages 배포 성공을 확인한다.
4. 배포된 상품 데이터의 수집 시각과 상품 수를 확인한다. 비밀값 등록만으로 연결 성공으로 표시하지 않는다.

이 API는 공시 상품 정보를 제공하며 본인의 계좌 잔액이나 거래를 가져오는 API가 아니다. 기존 실패 동작을 숨기거나 빈 데이터를 최신 상품 데이터로 바꾸지 않는다.

## 계좌 자동 조회 조사 결과

| 경로 | 확인한 내용 | 아직 확인할 사항 |
| --- | --- | --- |
| 금융결제원 오픈뱅킹 | 공식 안내에 개인 잔액·거래내역 조회가 있고 이용기관은 이용계약과 승인을 받은 사업자/기관으로 설명됨. 국민·카카오·토스 및 미래에셋의 전신 명칭이 참가 목록에 있음 | 개인용 개발 서비스의 이용 자격과 비용, 청약·적금·ISA·연금 계좌별 조회 범위, 인증/동의 방법 |
| CODEF 등 중계 서비스 | 공식 개발가이드와 데모/정식 서비스 경로가 있음 | 개인 개발자 이용 가능 여부, 계약/요금, 은행별 인증 방법과 실제 지원 상품. 이번 조사에서 확정하지 않음 |
| 미래에셋 직접 API | 공개 디지털엑스 API 문서를 확인함 | 해당 문서만으로 본인의 ISA·연금저축 조회 지원을 확인할 수 없음. 지원된다고 가정해 구현하지 않음 |

출처: [금융결제원 오픈뱅킹 안내](https://openapi.kftc.or.kr/service/openBanking), [CODEF 공식 개발가이드](https://developer.codef.io/), [CODEF 공식 서비스 소개](https://codef.io/assets/pdf/202308_CODEF%20API%20%EC%84%9C%EB%B9%84%EC%8A%A4%EC%86%8C%EA%B0%9C%EC%84%9C.pdf), [미래에셋 디지털엑스 API 문서](https://docs.digitalx.miraeasset.com/).

## 후속 구현 순서

1. 키 등록 후 기존 금융상품 갱신 검증. 계좌 자동 조회는 이용 자격·지원 상품·비용을 확정한 뒤 제공자를 선택한다.
2. 독립적으로 월별 계획 이력과 결산을 구현한다. 반복 납부 일정·거래 연결, 적금 만기 계획과 수령 확인, 목표 조정안 비교는 구현했으며 계획 적용은 사용자가 직접 수정한다.
3. 제공자 결정 후 서버 인증·비밀값 저장·토큰 갱신·사용자별 데이터 분리와 로그인/동기화를 구현한다. GitHub Pages의 브라우저 코드에 비밀키를 포함하지 않는다.
4. 읽기 전용 계좌 연동부터 연결하고 중복 수집·페이지 누락·재인증·실패 복구를 검증한다. 송금 기능은 범위에 포함하지 않는다.
5. 부채/카드 원장, 모바일 실기기 검증, 백업/복원 보강 후 필요하면 AI 설명 기능을 추가한다.

Excel/XLSX 가져오기는 추가하지 않는다. API가 준비되기 전에는 현재 수동 거래 입력을 유지한다.
