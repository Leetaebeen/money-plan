# 배분 계산 엔진 v1 명세

상태: 구현 완료, 베타 검증 전  
규칙 버전: `budget-allocation-v1.0.0`

## 1. 목적과 경계

이 엔진은 사용자가 입력한 월급, 필수지출, 목표와 직접 선택한 가정을 바탕으로 용도별 예산 시나리오를 계산한다.

엔진이 출력할 수 있는 버킷은 다음 네 가지뿐이다.

- 비상자금
- 사용자가 직접 등록한 목표
- 장기목표
- 미배정

엔진은 다음 정보를 구조적으로 출력하지 않는다.

- 은행 또는 금융상품명
- ETF·주식의 티커, ISIN 또는 수량
- 가입·매수·매도 시점
- 목표수익률 또는 예상수익률
- 자동 리밸런싱이나 거래 지시

상품 사실조회 화면과 이 배분 엔진은 별도 데이터 흐름으로 유지한다.

## 2. 사용자 결정 원칙

- 비상자금 목표 개월 수는 사용자가 직접 고른다.
- 목표 우선순위도 사용자가 직접 정한다.
- 장기목표 버킷을 사용할지도 사용자가 직접 정한다.
- 안전형·균형형·성장형은 항상 동등하게 보여주며 자동 선택하지 않는다.
- 세금 준비금과 여윳돈의 단기 사용 예정액도 사용자가 입력한다.
- 월 구조적 적자가 있을 때 여윳돈으로 몇 개월을 버틸지도 사용자가 선택한다.

## 3. 월급 계산

```text
핵심 월비용
= 고정 필수지출
 + 변동 필수지출
 + 비정기 필수지출 월 준비금
 + 약정 부채상환액

경성 잉여액 = 세후 월급 - 핵심 월비용

배분 가능액
= max(0, 경성 잉여액 - 계획한 자유지출 - 이번 주기 미충당 확정지출)
```

변동 필수지출이 입력되지 않으면 0원으로 추정하지 않고 계산을 중단한다. 핵심 월비용이 월급보다 크면 저축·장기목표 시나리오를 만들지 않고 구조적 적자만 표시한다.

## 4. 목표 계산

```text
목표 부족액 = max(0, 목표액 - 현재 적립액)
월 필요액 = ceil(목표 부족액 / 사용자가 입력한 남은 개월 수)
```

시나리오의 목표 버킷은 사용자가 정한 우선순위 순서대로 월 필요액까지만 배분한다. 남는 돈은 다른 버킷으로 자동 이동하지 않고 `미배정`으로 보낸다.

여윳돈에서는 사용자가 명시한 `목표 따라잡기 금액`까지만 목표 버킷에 반영한다.

## 5. 비상자금 계산

```text
비상자금 목표 = 핵심 월비용 × 사용자가 선택한 개월 수
비상자금 부족액 = max(0, 목표 - 현재 비상자금)
```

시나리오 비상자금 몫이 부족액을 넘으면 초과분은 `미배정`으로 보낸다. 고용형태, 나이, 부양가족 수로 목표 개월 수를 자동 결정하지 않는다.

## 6. 사용자 선택형 템플릿

| 버킷 | 안전형 | 균형형 | 성장형 |
|---|---:|---:|---:|
| 비상자금 | 60% | 40% | 25% |
| 사용자 목표 | 25% | 30% | 25% |
| 장기목표 | 5% | 20% | 40% |
| 미배정 | 10% | 10% | 10% |

이 비율은 초기 제품 정책값이며 최적안이나 금융상품 추천이 아니다. 각 시나리오에는 `사용자 선택 필요` 플래그가 포함된다.

배분액은 1,000원 단위로 내림하고, 반올림 잔액과 목표 상한을 넘는 돈은 미배정으로 보낸다. 각 시나리오의 합계는 항상 배분 가능액과 정확히 일치한다.

## 7. 여윳돈 계산

여윳돈은 다음처럼 사용자가 확정한 준비금을 먼저 분리한다.

```text
여윳돈
- 사용자가 입력한 세금 준비금
- 사용자가 입력한 단기 사용 예정액
- 월 구조적 적자 × 사용자가 선택한 대응 개월 수
= 시나리오 배분 가능액
```

월 구조적 적자가 있는데 대응 개월 수를 선택하지 않으면 시나리오를 만들지 않는다. 엔진이 임의의 세율이나 대응 기간을 정하지 않는다.

## 8. 필수 불변식

- 음수 금액을 출력하지 않는다.
- 입력 금액은 정수 원화만 허용한다.
- 월급 시나리오 합계는 월 배분 가능액과 같다.
- 여윳돈 준비금과 시나리오 합계는 입력한 여윳돈과 같다.
- 목표 배분은 목표 부족액 또는 사용자가 정한 따라잡기 금액을 넘지 않는다.
- 동일 입력, 기준일, 규칙 버전이면 동일 결과가 나온다.
- 계산결과에는 특정 상품·종목·거래·예상수익 필드가 존재하지 않는다.
- 불완전한 입력은 조용히 추정하지 않고 `INVALID`로 중단한다.

## 9. 결과 화면 고지

결과 가까이에 다음 취지의 문구를 표시한다.

> 입력값과 사용자가 선택한 가정에 따른 예산 계산·교육용 시나리오입니다. 특정 금융상품의 취득이나 처분을 권유하지 않습니다.

금융상품 사실조회 화면에는 별도로 다음 정보를 표시한다.

- 출처
- 데이터 기준일
- 마지막 확인시각
- 지연 가능성
- 실제 가입 전 금융회사 공시 확인 필요

## 10. 후속 버전으로 보류한 항목

다음은 법률 검토와 적절한 등록·제휴 체계 전까지 구현하지 않는다.

- 금리를 이용한 부채 자동 등급 분류
- 위험성향으로 특정 템플릿 자동 선택
- 특정 ETF 또는 예적금에 배분액 자동 연결
- 기대수익률을 이용한 최적화
- 자동매매, 자동 리밸런싱, 가입 딥링크
